# DBMS Practicals

This repository contains 10 DBMS practicals with SQL examples.

## Database
The main examples are written for MySQL 8.0+. Some commands differ in Oracle or PostgreSQL, and those cases are mentioned in the relevant practical.

## Files
1. `Practical_01_DBMS_Architecture.sql`
2. `Practical_02_ER_and_Schema.sql`
3. `Practical_03_DDL_and_Constraints.sql`
4. `Practical_04_DML_and_Select.sql`
5. `Practical_05_DCL_and_TCL.sql`
6. `Practical_06_Operators.sql`
7. `Practical_07_Set_Operations.sql`
8. `Practical_08_Joins.sql`
9. `Practical_09_Aggregate_Functions.sql`
10. `Practical_10_Subqueries_Views_Sequences_Indexes.sql`

## How to run
Open a practical in MySQL Workbench or another MySQL client and run the statements in order. Some practicals create or change tables. Use a test database rather than a database containing important data.

The ER diagram for Practical 2 is included as a Mermaid diagram in that SQL file's comments.
